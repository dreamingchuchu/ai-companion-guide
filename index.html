长期记忆与用户画像

方案 架构 性能 适用场景
🏆 Zep 时间知识图谱（Episode → Entity → Community 三层子图） DMR 94.8% · 延迟 ↓90% 生产级，动态演化数据
Mem0 轻量级记忆提取 + 向量检索 批量处理降成本 96% 嵌入式场景，快速集成
MemMachine 地面实况保留 + 层级压缩 LongMemEvalS 93% · 减少 80% token 高精度要求场景
MemGPT (Letta) OS 式分层记忆（核心 → 召回 → 归档） DMR 93.4% 经典方案，自管理记忆
ChromaDB + SillyTavern 全本地 RAG 向量检索 8GB 显存可跑 隐私优先，全本地部署

💡 2025-2026 趋势：已从简单 RAG 管道进化到自管理、层级化记忆架构。 核心创新包括——策略性遗忘（避免上下文污染）、情景→语义转化（例如"她昨天说喜欢早上"→"用户偏好上午沟通"）、 时间感知（知道何时发生何事）。

情感语音合成 (TTS)

模型 延迟 情感控制 声音克隆 许可 语言
🏆 Qwen3-TTS 97ms 文本提示情感 3秒音频 Apache 2.0 10种
Chatterbox TTS <200ms 情感夸张度滑杆 5秒音频 MIT 23种
Orpheus TTS 25-200ms 行内标签 <laugh> <sigh> 零样本 开源 英文
GLM-TTS 流式 RL 优化情感表达 3-10秒 开源 中英
CosyVoice2 实时 中文自然语音 支持 开源 中文
GPT-SoVITS 非实时 参考音频驱动 少样本微调 开源 中英日韩粤

💡 中文场景推荐：CosyVoice2 (TTS) + SenseVoice (ASR) 组合。 多语言场景：Qwen3-TTS 或 Chatterbox TTS。 2025-2026 年TTS 已从"朗读"进化到"表演"——情感不再是附加功能，而是标配。

推荐入门路线图

🚀 路线A：零编程快速体验（1-3天）

1

安装 Ollama + 拉取本地模型

安装 Ollama → 运行 ollama pull qwen2.5:7b

2

克隆快速启动项目

git clone https://github.com/MrRuicy/ai-girlfriend-chatbot

3

一行启动

pip install -r requirements.txt && python main.py → 浏览器打开 http://localhost:8000

🔧 路线B：全栈开发者深度构建（2-4周）

W1

第 1 周：基础对话系统

FastAPI + Ollama + SQLite 后端，React / 微信风格 UI 前端，角色设定 + 情感标签 Prompt 设计

W2

第 2 周：记忆系统

ChromaDB / Qdrant 向量存储，Mem0 记忆提取与检索，用户画像动态更新

W3

第 3 周：语音 + 表情

Whisper / SenseVoice ASR，CosyVoice2 / Qwen3-TTS 语音合成，Open-LLM-VTuber Live2D 集成，实时流式对话

W4

第 4 周：打磨上线

情感检测增强（SoulSync 参考），主动联系机制（revive-companion 参考），公网部署（内网穿透 / 云服务器）
